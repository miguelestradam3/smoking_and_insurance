# Smoking Analysis

Using `scikit-learn` for data analysis and predictive modeling within Python/Jupyter Notebook.

## Project Overview

This project analyzes health and lifestyle factors related to individuals, focusing primarily on smoking status, attributes like BMI, age, and their resulting implications on insurance charges. The development process incorporates data cleaning, database interactions via SQL, exploratory data analysis with visualization, data balancing, and predictive modeling using Logistic Regression.

## Technical Stack & Dependencies

The project relies on the following Python packages:
* **Data Manipulation:** `pandas`, `numpy`
* **Database Management:** `sqlite3`
* **Data Visualization:** `seaborn`, `matplotlib`
* **Machine Learning & Preprocessing:** `scikit-learn`
* **Imbalanced Data Handling:** `imbalanced-learn` (`imblearn`)

To install the necessary dependencies, make sure you have a `requirements.txt` file configured and run:
